# 🚀 ZEROHUB HTML to APK Converter

## **ДАСТУРИ ҚАДАМ БА ҚАДАМ**

### **ҚАДАМ 1️⃣ : Насб Node.js**
- Рифта: https://nodejs.org/
- Боргирӣ ва насб кунед (v14+)

### **ҚАДАМ 2️⃣ : Папка сохт**
```bash
mkdir zerohub-apk
cd zerohub-apk
```

### **ҚАДАМ 3️⃣ : Файлҳо истифодаи**
- `index.html` - Интерфейси веб
- `server.js` - Бекенд Node.js
- `package.json` - Вобастагиҳо

### **ҚАДАМ 4️⃣ : Вобастаги насб**
```bash
npm install
```

### **ҚАДАМ 5️⃣ : Сервер оғоз**
```bash
npm start
```

### **ҚАДАМ 6️⃣ : Браузер кушоез**
```
http://localhost:3000
```
